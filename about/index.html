About ¶

I am Yuri Egorov, software developer currently living in Moscow, Russia.

Summary ¶

I think of myself as a generalist. I try to use simple solutions when possible to have control over project. I prefer to be focused on something. It can be a project, a library or anything else. This way I can be sure I'll be effective in my work.

In my day-to-day work I am using python for backend tasks and javascript for frontend tasks and can write HTML/CSS/SASS/LESS when it's neсessary. Some time ago I worked with jython for some specific tasks.

My basic toolchain consists of django / starlette / sanic web frameworks for backend tasks.

For frontend tasks I'm exploring functional programming and find it very interesting. I've developed @yagni-js - several open-sourced (unlicensed) javascript libraries, made with functional and stateless mantras in mind (not in development at the moment).

Working for Chtd I've created frontend js bundler using nodejs.

I've worked with MySQL, PostgreSQL and MongoDB and in case I would have to pick one PostgreSQL will be my choice. Redis is my choice of fast in-memory storage.

I write code in helix and vim and use git on a daily basis.

I run Linux on my desktop since 2003. Since 2012 till 2022 I was running ArchLinux and since 2022 I am running VoidLinux on my laptop. Before ArchLinux I was using RedHat and Gentoo and besides I have experience working with Alpine, Ubuntu and CentOS.

I am administering FreeBSD on several virtual private servers since 2022.

I can deploy and manage Linux or FreeBSD server and can configure network services when needed (dns, web, email and others).

I have experience working (which means deployment and everyday usage) with jenkins, sentry and worked with AWS, Digital Ocean and Linode.

From time to time I'm using ansible and vagrant.
